# Executive Sales Dashboard (Power BI)

## Overview
Manager-ready interactive dashboard built from the NorthStar Capital dataset. Features KPI cards, slicers, matrix with data bars, and drill-through to client details.

## Tech Stack
Power BI Desktop, DAX, CSV

## Key Features
- 4 KPI cards with visual-level filters
- Interactive slicers for Region and Category
- Matrix visual with revenue, percentage of total, and data bars
- Drill-through page for individual client records
- Custom DAX: CALCULATE, ALL(), DIVIDE

## Key Results
| Metric | Value |
|--------|-------|
| Total Revenue | 111.52K |
| Avg Order Value | 1.12K |
